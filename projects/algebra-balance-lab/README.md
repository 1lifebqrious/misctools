# Algebra Balance Lab

A graph-first algebra tool for grades 6-8.

## Concepts

- Noob: one-variable equations as a line meeting a target line
- Pro: two-variable systems as two lines meeting at one solution point
- Practice mode with prewritten problem prompts and deterministic hints

## Local development

```bash
pnpm install
pnpm --filter @misctools/algebra-balance-lab dev
```

## Build

```bash
pnpm --filter @misctools/algebra-balance-lab build
pnpm --filter @misctools/algebra-balance-lab build:pages
```

## Tests

```bash
pnpm --filter @misctools/algebra-balance-lab test
```
